# STAT184_HW4.3
Homework 4.3 of STAT184
## Project Description   
The main purpose of this assignment is to create a reproducible data analysis report using Quarto and R.
The report includes five main sections:
1.Diamonds Table of Statistics: Create three tables of descriptive statistics for diamond length, width, and depth, grouped by cut quality.
2.Big 10 Academic Alliance - Love Data Week: Present a data visualization and explain the main patterns.
3.Monte Carlo Numerical Integration: Use Monte Carlo simulation to estimate an integral and compare the results from different sample sizes.
4.Planning and Prompting GenAI Tools: Create a plan for tidying the calcium dataset and making a visualization, then compare the results from a plan-based prompt and a generic prompt.
5.Reflection: Reflect on what I have learned from the course.
6.GenAI Usage Appendix: Explain which AI tool was used to generate text and include the complete conversations with the AI.
7.Code Appendix: Include all the code used to generate the PDF report.
## Data Sources
